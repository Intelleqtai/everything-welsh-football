About the numbers

Attendances are published match figures, not unique people. Missing figures stay missing. Every average uses only recorded attendances; totals are sums, never estimates.

Home-club filters describe crowds at that club’s ground. Opponent names do not imply a count of travelling supporters. Calendar weeks run Monday–Sunday in UK time; matchdays follow the league rounds.

Growth compares averages, not sums. Period changes compare adjacent selected periods using the same filters. Incomplete attendance coverage is marked. Full-season comparisons use 2025/26’s full available record; same-matchday comparisons use the selected round range. Clubs outside last season’s Cymru Premier have no league baseline here.

Match records through 5 September and the 2025/26 baseline are copied from the frozen study extract. Later records were checked against Football Web Pages on 20 September 2026. Weather: Open-Meteo historical estimates using the original ground coordinates. This dashboard is a dated snapshot, not a live feed.
